# Mission ideas

## Look Closely
- Find something with more than one part.
- Find two objects that are the same in one way.
- Find two objects that are different in one important way.
- Find something that opens and closes.

## Oops, Beaver!
- Show Beaver a familiar object.
- Show an object from a strange angle.
- Show something partly hidden.
- Find something Beaver might confuse with something else.

## Predict First
- Predict what Beaver will call the object.
- Predict which of two objects will roll farther.
- Predict which is heavier.
- Predict what will happen if a tower gets taller.

## Convince Beaver
- Convince Beaver that an object belongs in a category.
- Convince Beaver that one object does not belong.
- Convince Beaver which of two solutions is stronger.
- Convince Beaver that two objects belong together.

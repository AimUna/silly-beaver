# Silly Beaver V0.2

## Purpose
A screen-free kindergarten thinking companion using a hidden smartphone.

The phone acts as:
- rear camera
- microphone
- speaker
- processor

Teacher chooses the mode before the session.

## Modes
1. Look Closely — observation + description
2. Oops, Beaver! — error detection
3. Predict First — child commits before machine checks
4. Convince Beaver — reasoning + evidence

## Run
Camera access needs HTTPS.
Upload this folder to Netlify Drop, GitHub Pages, or another static HTTPS host.
Open the URL on the phone and allow camera + microphone.

## Physical Beaver
Use a wide horizontal camera window, not a fixed lens hole.
Recommended opening: about 8–10 cm wide × 3–4 cm high.
Use an adjustable internal phone tray and a large back access door.

## What to test
- Does the child talk to Beaver naturally?
- Does the child enjoy correcting Beaver?
- Does the child explain their reasoning?
- Does Predict First reduce passive waiting for answers?
- Does the child challenge the machine?
- Which missions produce the most persistence?

Recognition accuracy is not the primary outcome in V0.2.
